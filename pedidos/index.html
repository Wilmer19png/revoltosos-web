¿Qué anuncios están funcionando?

AnuncioGastoClicsCompras (Meta)PedidosEntregadosEn caminoCosto x entregadoGanancia netaSugerencia

«Compras (Meta)» es lo que reporta el Pixel. «Pedidos» y «Entregados» salen de tu gestor, por el anuncio de donde llegó el cliente. La ganancia neta resta el gasto del anuncio a la ganancia de sus pedidos entregados (y las devoluciones). La sugerencia es una guía: revísala antes de decidir.

Para que cada pedido sepa de qué anuncio vino

En el Administrador de anuncios, en cada anuncio → Parámetros de URL, pega esto (una sola vez por anuncio):

utm_source=facebook&utm_medium=paid&utm_campaign={{campaign.name}}&utm_content={{ad.id}}&utm_term={{adset.name}}

Meta reemplaza lo que está entre llaves por el nombre y el ID reales. Los pedidos que lleguen sin esto aparecen como «Sin anuncio identificado».

Envío al cliente

Tarifa distinta por departamento (opcional)

Déjalo vacío para usar la tarifa normal. Cuando conectemos Envía, esto se calcula solo.

Tarifa para ciudades puntuales (opcional)

Gana sobre la del departamento. Úsala para las ciudades a las que más vendes o las que salen más caras (municipios lejanos).

Cómo sacar las tarifas del cotizador de Envía
  1. Entra a envia.com → Cotizar envío (no necesita cuenta).
  2. Origen: tu ciudad. Destino: la capital de cada departamento (y las ciudades donde más vendes).
  3. Paquete: la caja que usas con el peso de un pedido típico (por ejemplo 1 kg).
  4. Activa pago contra entrega si la opción aparece, para que el precio incluya el recaudo.
  5. Anota el precio de la transportadora que vas a usar (por ejemplo Interrapidísimo) y ponlo aquí. Si quieres, súmale un margen para cubrir variaciones.

Los precios cambian con el peso: si un pedido es mucho más pesado que el típico, revisa el valor antes de despachar.

Costos internos (no los ve el cliente)

Se usa el promedio mientras no anotes el envío real de cada pedido. Si generas la guía con Envía, el envío real se anota solo (y ya incluye la comisión de recaudo: en ese caso deja la comisión en 0).
